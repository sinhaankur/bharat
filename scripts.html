The two trees of Bharat

India's languages come from families that are genuinely unrelated — Tamil is Dravidian, Sanskrit is Indo-European; neither descends from the other. Yet almost every Indian script descends from one ancestor: Brahmi, attested in the Edicts of Ashoka around 250 BCE. So a language tree and a script tree tell different stories — the languages diverge, the writing systems converge. That single fact is what makes a modern neutral link-script (Bharati, IIT Madras) even conceivable.

This page keeps a language and the script it is written in strictly apart — because they are different inheritance trees. Sanskrit was written in many scripts long before Devanagari; Tamil's script is Brahmi-descended though its language is not. We flag dead languages, dead scripts, and Brahmi's own contested parentage — established fact and disputed interpretation kept separate, as on the DNA page.

Truth 1 · languages diverge Tamil ≠ Sanskrit. Tamil belongs to the Dravidian family and is not derived from Sanskrit. Sanskrit is Indo-European (kin to Latin, Greek, Persian). They are foreign to each other.
Truth 2 · scripts converge Yet the Tamil script and Devanagari both descend from Brahmi. Unrelated languages, one shared script-ancestor. That is why one link-script across both families is structurally possible.

Our own type: the “Bharati Inspired” font

We built an original, open (OFL) display font from the Bharati design principles — monoline strokes, open counters, and no Devanagari-style headline bar — with a reproducible build_bharati_font.py (fontTools). It is Bharati-inspired, not the IIT Madras glyphs. Type below to try it; source & license are in assets/fonts/.

Bharat
Aa Bb Gg 0123456789 The quick brown fox jumps over the lazy dog.
How to use it 
/* 1. the @font-face is already in styles.css */
/* 2. apply the class, or the family name directly */
<h1 class="bharati">Bharat</h1>

.my-heading { font-family: "Bharati Inspired", sans-serif; }

/* rebuild the font from source: */
python3 -m venv .venv-font
