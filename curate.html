Local moderation & anchoring tool — not for the public site

Curate the feed

Review aggregated news, confirm which district/scheme each item belongs to, link it to a fund story so it strengthens that event's coverage bar, then approve or reject. Decisions are saved in your browser; Export when done and run apply_curation.py to write the approved, anchored set into the site.

⚠ Run this locally (python3 -m http.server then open this page). It needs news-feed.json (generated by ingest_news.py), which is gitignored and not on the public site. Nothing here writes to the server — it can only export a file you commit.
