Words and craft · The script family tree

One ancestor, many alphabets

Two family trees kept apart: how India's languages descend (Indo-Aryan vs Dravidian) and how their scripts descend (nearly all from Brahmi) — with the modern Bharati link-script.

How we knowCompiled from paleography and historical linguistics; Brahmi's contested parentage is flagged, not resolved. Every script renders in a self-hosted OFL font so specimens never break.

One word, many letters

The same sounds, written in scripts that look nothing alike. Language and script are separate trees.

The script family

ScriptBranchDescends fromStatusPeriodNote
Indus (Harappan) scriptpre brahminoneundeciphered dead~2600–1900 BCEThe seals of the Indus Valley Civilisation. NEVER deciphered; we don't know if it's even full writing. A minority theory makes it Brahmi's ancestor (the 'indigenous origin' view) — unproven, and separated from Brahmi by ~1500 years with no attested writing in between.
Brahmirootaramaic, uncertaindead≥3rd c. BCE – 5th c. CETHE ROOT of nearly every Indian script (and ~198 scripts across South & SE Asia). An abugida — consonant + inherent vowel — the structural pattern every descendant inherits. Now a DEAD script (nobody writes Brahmi today) though it IS in Unicode. Its own PARENT is genuinely disputed: the dominant Western view derives it from the Semitic/Aramaic alphabet (Weber 1856, Bühler 1895); an indigenous view ties it to the Indus script; both remain debated. We flag the parentage, we do not resolve it.
Kharoshthisiblingaramaicdead~4th c. BCE – 3rd c. CEA SIBLING of Brahmi, not a child — the other ancient script of the subcontinent, used in the northwest (Gandhara). Written right-to-left, derived from Aramaic. Left NO living descendants and died out by the 3rd c. CE. A dead branch of the tree.
Gupta (Late Brahmi)northBrahmidead~4th–6th c. CEThe transitional 'Late Brahmi' of the Gupta empire — the hinge from which the Northern scripts (Nagari → Devanagari, Sharada, Siddham) fan out. Dead itself, but the direct ancestor of Devanagari.
NāgarīnorthGupta (Late Brahmi)dead~7th–13th c. CEThe medieval script between Gupta and modern Devanagari.
DevanagarinorthNāgarīliving~13th c. CE – presentThe most-used Brahmic script today — Hindi, Marathi, Nepali, and the default modern script for Sanskrit. Note the headline (shirorekha) bar across the top of letters, which Bharati deliberately drops. Indo-Aryan side of the tree.
SharadanorthGupta (Late Brahmi)near dead~8th c. CE – present (ritual)The old script of Kashmir, once used for Sanskrit and Kashmiri; now nearly dead, surviving mainly in ritual use. Ancestor of Gurmukhi via the Landa scripts.
GurmukhinorthSharadaliving~16th c. CE – presentThe script of Punjabi (Indo-Aryan), standardised for the Sikh scriptures. Descends from the Sharada/Landa line.
Bengali–AssamesenorthGupta (Late Brahmi)livingpresentWrites Bengali, Assamese, and (historically) Meitei. Like Devanagari it keeps a headline bar. Eastern Indo-Aryan side.
OdianorthGupta (Late Brahmi)livingpresentIts distinctive curved letters come from writing on palm leaves (straight strokes would split the leaf). Indo-Aryan.
GujaratinorthNāgarīlivingpresentA Nagari-derived script that DROPS the top headline bar — the same feature Bharati borrows for a cleaner, more Latin-like line.
Meitei MayeknorthBrahmirevivedrevived 20th c.The indigenous script of Meitei (Tibeto-Burman), revived after centuries of the language being written in Bengali–Assamese.
Tamil-BrahmisouthBrahmidead~3rd c. BCE – 5th c. CEThe southern adaptation of Brahmi that first wrote Old Tamil — the start of the Dravidian side of the SCRIPT tree (the LANGUAGE stays Dravidian throughout).
VaṭṭeḻuttusouthTamil-Brahmidead~6th–14th c. CE'Rounded script' — the medieval Tamil/Malabar script between Tamil-Brahmi and the modern Tamil script.
Tamil (modern script)southVaṭṭeḻuttulivingpresentThe living Tamil script — Brahmi-descended like Devanagari, even though the Tamil LANGUAGE is Dravidian and unrelated to Sanskrit. This split (shared script-ancestor, unrelated languages) is the whole story.
GranthasouthBrahminear dead~6th c. CE – present (limited)The southern script used to write SANSKRIT (which Tamil script could not fully represent). Grantha is the bridge that seeded the Malayalam script — a neat proof that Sanskrit rode on many scripts. Now nearly dead.
TelugusouthBrahmilivingpresentTelugu and Kannada scripts split from one common Kadamba ancestor; rounded forms, no headline bar. Dravidian language.
KannadasouthBrahmilivingpresentSister script to Telugu from the Kadamba/Old-Kannada line. Dravidian language.
MalayalamsouthGranthalivingpresentGrew from Grantha (+ Vaṭṭeḻuttu) — so a Dravidian language written in a script that came partly through the Sanskrit-writing Grantha line. The trees cross here.
SinhalasouthBrahmilivingpresentSri Lanka. Writes Sinhala (Indo-Aryan!) and, liturgically, Pali — an Indo-Aryan language in a Southern-branch script, showing the script/language trees are independent.
Burmesesoutheast asiaBrahmilivingpresentBeyond India: Brahmi (via Pallava/Mon) seeded the scripts of Burma, Thailand, Cambodia, Laos, Bali and the Philippines — ~198 scripts in all. Rounded to suit palm-leaf writing.
Thaisoutheast asiaBrahmilivingpresentVia Khmer ← Pallava ← Brahmi. Writes Thai and, liturgically, Pali. The Brahmic family reaches the whole of mainland Southeast Asia.
Ol Chikimodern purpose builtnonelivingcreated 1925A PURPOSE-BUILT script (Raghunath Murmu, 1925) created to give Santali (Austroasiatic) its own writing — NOT Brahmi-derived. The direct precedent for the idea of deliberately designing a script for a language that lacked one — which is what Bharati does, but for all of them at once.
Bharaticonstructed linknoneproposeddeveloped c. 2011–2018A CONSTRUCTED link-script — one neutral abugida meant to write ALL of India's 22 scheduled languages, across BOTH the Indo-Aryan and Dravidian families, the way the Latin alphabet serves Europe. It borrows glyph elements from Devanagari, Tamil, Telugu, Kannada, Malayalam, Bengali–Assamese and Latin, and drops the top headline bar (like Gujarati). It is NOT descended from Brahmi — it is designed — but it only works BECAUSE all those scripts share Brahmi's abugida structure. Status: a proposal, NOT adopted into Unicode — so unlike ancient dead Brahmi, this modern script has no code block yet. Whether such a link-script is desirable is genuinely contested (Tamil script-pride and anti-imposition politics in particular).
