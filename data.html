Read it as an API

No server, no key — fetch the static JSON and index into it. CORS-open via GitHub Pages.

// base
const BASE = "https://sinhaankur.github.io/india-fiscal-map";

// whole ledger, then one district
const led = await fetch(`${BASE}/district-ledger.json`).then(r => r.json());
const kol = led.states["West Bengal"].districts["Kolkata"];

// the governance protocol registry (constitutional list, funding, authority)
const reg = led._meta.scheme_registry;     // scheme → protocol
const auth = led._meta.authority_map;       // post  → who appoints
